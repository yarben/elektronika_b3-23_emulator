# Electronika B3-23 Web Emulator

A functional web-based emulator of the historic Soviet digital calculator **"Electronika B3-23"** (Электроника Б3-23), originally released in 1976.

## Features
* **Authentic Logic:** Accurate replication of the original calculator's arithmetic operations and display behavior.
* **Responsive UI:** Retro-inspired user interface designed to match the visual style of the physical device using HTML and CSS.
* **Pure JavaScript:** Built completely client-side without heavy external frameworks.

## Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript# Electronika B3-23 Web Emulator
